# WORLDBOUND: NOMAD — Design

> Visual identity spine. Behaviour lives in [EXPERIENCE.md](EXPERIENCE.md). Visual references: the mockup files and frames in EXPERIENCE.md → Visual References, and the pitch-deck import in EXPERIENCE.md → Inspiration & Anti-patterns. **The spines win on conflict with any mockup.**

## Brand & Style

The pitch poster, made playable. WORLDBOUND: NOMAD looks like a traveller's journal laid on a sunny table: warm paper, navy ink, ochre accents, a real-looking world map, and a passport that fills up with round ink stamps. The layout is spacious and a little editorial: serif numerals and headlines, quiet sans-serif chrome. It should feel adventurous, clean and modern (PRD §7). It should never feel like a casino or a dashboard.

The rewards are physical objects, not effects. A stamp lands in the passport and a polaroid joins the album, with no confetti, coins or flashing. Not reaching the goal looks like a calm statement, not a failure screen: no red and no crossed-out stamps.

The base is direction A (Sunrise Expedition), with three elements borrowed from other directions: the day chip from B (Night Route) (calendar icon, bold "Day X of 30", a second line "N days left"), and the round code stamps and always-visible passport strip from D (Passport Atlas). One identity carries across the game, the presentations and the documentation (PRD §7).

### Logo

| Aspect | Spec |
|---|---|
| Content | The **WORLDBOUND** wordmark only. NOMAD is **not** part of the logo. The mode (Explorer / Nomad) has its own place on the passport cover. |
| Format | **One SVG asset** (wordmark, compass-rose O and mountain line drawn as paths). Until the clean vector redraw exists, the app ships the stand-in from the renders (type plus SVG). `{typography.wordmark}` / `{typography.wordmark-xl}` apply only to fallback text (for example the accessible name). Colour `{colors.ink}` via `currentColor`. |
| Compass-rose O | The O is a compass rose: a ring (stroke about 13% of the glyph), a north needle in `{colors.logo-ochre}` and a south needle in ink. The glyph is 16 px at the 19 px size and 32 px at the 38 px size. |

## Typography

Both type families use **system font stacks only**; no web fonts are downloaded (decided). The named faces are used where the device already has them; otherwise the stack falls back to `system-ui` or Georgia. The pptx font (Aptos) was not adopted. All sizes are set in `rem` (base 16 px) so browser text size scales them.

- **Serif** (`Iowan Old Style → Palatino → Georgia`) is the journal voice. It sets headlines, numbers that matter (day, money, prices, counts), fact text and trivia questions. Numerals are always `lining-nums tabular-nums` so the counters never jitter.
- **Sans** (`Avenir Next → Segoe UI → system-ui`) is the chrome. It sets labels, buttons, row titles, captions and inputs.

| Role | Token | Where |
|---|---|---|
| Journey-end headline | `{typography.display}` | Journey summary ("What an adventure.") |
| Screen and sheet titles | `{typography.headline}` | "A day in Paris", "Welcome to Paris", "Paris, stamped." |
| Route sheet title, can't-continue headline, passport-screen count | `{typography.headline-sm}` | "Paris → London" |
| Panel title | `{typography.title}` | Resting panel ("You're in Paris") |

Rules:

- No all-caps sentences. Caps are only for eyebrows, the mode word and chip labels.
- Text in inputs is at least 16 px.
- **All text is at least 11 px** (NFR-5), including chip sublabels, slot numerals, map labels, the slim-strip mode and the passport mode row.
- **Stamp-code exception (approved):** inside stamps smaller than 70 px, `{typography.stamp-code}` is in stamp viewBox units, so it renders at about **4.5–4.8 px** in the 28–30 px strip, cover and map stamps (8 px at 50 px, 12.8 px at 80 px). There it is part of the stamp graphic, and the city name is always present as text or as the accessible label.

## Layout & Spacing

The scale is `{spacing.1}` 4 · `{spacing.2}` 8 · `{spacing.3}` 12 · `{spacing.4}` 16 · `{spacing.5}` 20 · `{spacing.6}` 24 · `{spacing.7}` 32, plus `{spacing.stack-tight}` (6 px) between stacked rows and chips whose tap only selects (nothing commits or opens), and `{spacing.stack-tap}` (8 px) between adjacent targets that act on a single tap (answer rows, sight cards, destination chips).

Sizes in this file are **minimums**, not fixed heights. Layout is stated as constraints so a real layout engine can satisfy them.

| Constraint | Rule |
|---|---|

| Gutters | Top bar `{spacing.gutter-bar}` (16 px). Pages and sheets `{spacing.gutter}` (20 px). |
| Top stack | Identical on every in-journey screen: logo row, status row (two chips at least `{spacing.status-chip-height}` tall; the day chip is 1.5× as wide as the money chip), then the passport. The Map uses the slim `passport-strip`; City day, Day complete and Shift result use the full cover (`{spacing.cover-height}`). The map starts directly below the top stack. |
| Strip vs loupe | The strip's `{spacing.strip-hit}` hit area takes precedence. The loupe's hit circle is clipped so it starts below the strip's hit area. |
| Map screen | The map fills the space between the top stack and the bottom panel, at least `{spacing.map-min-height}`. ## Elevation & Depth

Depth is paper on a table: warm, low, soft shadows tinted brown (`rgba(60,40,10,…)`), never grey.

| Level | Shadow (light) | Used for |
|---|---|---|
| Flat | none, `rule` border | Chips, rows, cards in flow |
| Lifted | `0 8px 20px -12px rgba(60,40,10,.5)` | City-day card floating on the map; city pills use `0 4px 10px -6px` |
| Object | `0 8px 16px -10px rgba(60,40,10,.55)` | Polaroids. Paper objects get a slight rotation (±2–2.5°). Stamps get their per-destination angle (see Stamp). |
| Sheet | `0 -10px 30px -12px rgba(60,40,10,.3)` + `scrim` | Resting panel and modal sheets |
| Cover | `inset 4–6px 0 0 {spine}` | Passport covers and mini covers get a book-spine edge |

Dark mode: shadows are dropped (confirmed in DM1). Layering comes from tone (`unavailable-dark` < `background-dark` < `surface-dark` < `surface-selected-dark`). Sheets and the resting panel get a 1 px `rule` top edge so they stay distinct from the map. These values are the full elevation spec; the DESIGN.md format has no token keys for shadows.

## Do's and Don'ts

| Do | Don't |
|---|---|
| Show state by shape, word or icon **plus** colour: stamp code + check, dashed vs solid, block icon vs radio, "Empty", "No direct route", "€60 short" | Use colour alone, red for errors or failure, or green for success |
| Keep the logo to WORLDBOUND with the compass-rose O and mountain line, shipped as SVG | Put NOMAD, the poster's brush script or the pptx tagline in the logo, or rebuild it from a system font |
| Show the mode only on the passport cover (and the mode cards on the start screen) | Add a header badge or status chip for the mode (rejected variants M1/M2) |
| Stack the full cover in three rows: mode / name / count | Put mode and name side by side ("EXPLORER PASSPORT · Ingrid") |
| Let rewards be objects: a stamp lands, a polaroid joins the album | Use confetti, coins, sparkles, slot-machine reveals or streak counters (PRD §7) |
| Use serif tabular numerals for every day, money and price value | Use proportional numerals that shift as values change |
| Show the region the traveller is in inside the loupe | Show a Europe loupe while the traveller is in Tokyo, New York or Sydney |
| Draw places as line art without people, avoiding landmark clichés on street drawings | Use stereotyped depictions of places or people (PRD §7) |
| Keep `ochre` for non-text marks and use `ochre-text` for text and map route dashes | Set ochre `#B9761A` text on paper (3.2:1) or dash routes in it on the map (2.4:1 on land) |
| Bind interactive navy to `primary` (+ `on-primary-accent` icons) and decorative navy to `navy-fill` | Put `ochre-light` or `on-navy` content on `primary`: in dark mode it vanishes |
| Keep the bottom panel the same size for resting and route states | Resize the map when a sheet opens |

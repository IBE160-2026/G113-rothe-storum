Sunrise Expedition, refined

This builds on A2. The decisions below are locked and used in every frame here:

  • The mode is printed on the passport cover (M3). Explorer has a navy cover with a compass. Nomad has an ochre cover with a mountain. The header badge is gone.
  • The map stays geographic, with the magnifying loupe over Europe.
  • The status row shows only Day and Money. The stamp count is on the passport.

What changes in dark mode
  • The Explorer cover becomes almost black (#0A121A) with light ochre text. The Nomad cover becomes light ochre (#E0A243) with navy text. You can tell the modes apart by the word and the glyph, not just the colour.
  • The stamp ink turns cream, and the code and check mark stay.
  • The before/after boxes sink into the background (#0F1B26). The "from" value is muted and the "to" value is bold, so the order reads even without colour.
  • The primary button flips to light ochre with navy text, so it stays the brightest thing on the screen.
